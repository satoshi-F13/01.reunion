## 外語高校とは

**神奈川県立外語短期大学付属高等学校**（かながわけんりつ がいごたんきだいがくふぞくこうとうがっこう）は、かつて[神奈川県](https://ja-wikipedia-org.translate.goog/wiki/%E7%A5%9E%E5%A5%88%E5%B7%9D%E7%9C%8C?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "神奈川県")[横浜市](https://ja-wikipedia-org.translate.goog/wiki/%E6%A8%AA%E6%B5%9C%E5%B8%82?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "横浜市")[磯子区](https://ja-wikipedia-org.translate.goog/wiki/%E7%A3%AF%E5%AD%90%E5%8C%BA?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "磯子区")岡村にあった[公立](https://ja-wikipedia-org.translate.goog/wiki/%E5%85%AC%E7%AB%8B%E5%AD%A6%E6%A0%A1?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "公立学校")[高等学校](https://ja-wikipedia-org.translate.goog/wiki/%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "高等学校")。[神奈川県立外語短期大学](https://ja-wikipedia-org.translate.goog/wiki/%E7%A5%9E%E5%A5%88%E5%B7%9D%E7%9C%8C%E7%AB%8B%E5%A4%96%E8%AA%9E%E7%9F%AD%E6%9C%9F%E5%A4%A7%E5%AD%A6?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "神奈川県立外語短期大学")の[附属学校](https://ja-wikipedia-org.translate.goog/wiki/%E9%99%84%E5%B1%9E%E5%AD%A6%E6%A0%A1?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "附属学校")で、通称は「**外短**」（がいたん）または「**外語**」（がいご）。[2008年](https://ja-wikipedia-org.translate.goog/wiki/2008%E5%B9%B4?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "2008年")に[神奈川県立六ツ川高等学校](https://ja-wikipedia-org.translate.goog/wiki/%E7%A5%9E%E5%A5%88%E5%B7%9D%E7%9C%8C%E7%AB%8B%E5%85%AD%E3%83%84%E5%B7%9D%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "神奈川県立六ツ川高等学校")と統合され、[神奈川県立横浜国際高等学校](https://ja-wikipedia-org.translate.goog/wiki/%E7%A5%9E%E5%A5%88%E5%B7%9D%E7%9C%8C%E7%AB%8B%E6%A8%AA%E6%B5%9C%E5%9B%BD%E9%9A%9B%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1?_x_tr_sl=ja&_x_tr_tl=it&_x_tr_hl=it&_x_tr_pto=sc "神奈川県立横浜国際高等学校")となる。\

## 用語解説

| 用語 | 意味 |
|------------------------------------|------------------------------------|
| きざはし | 校歌の歌詞にもでてくる、外語高校の象徴的存在。登校中に存在した約151段の石段。弘明寺駅から校舎まではこの石段か自動車道路の激坂をと反しなければ校舎にはたどり着かない。入学後に10㎏痩せた生徒もいるとかいないとか。 |
| ＣＲ | Ｃｌａｓｓ　Ｒｏｏｍの略。通常1組、2組との日本の学校ではクラスを分類わけされるが、外語高校ではＣＲと呼ぶ。 |
| 弘明寺駅 | 外語高校の最寄り駅。横浜市営地下鉄及び京急線の停車駅でもある。また、横浜市営バスも停車する。多くの生徒が登校する際にこの駅をりようした。 |
| 神奈川県立外語短期大学 | 付属の短期大学。外語高校の最終学年には総合学習というカリキュラムがあり、短期大学の講師・助教授・教授との教育的交流を深める機会があった。また、高校生も短大の図書館を利用することは可能だったが、利用している生徒はいたとかいないとか。 |
| ニガイ | カリキュラムに含まれていた第二外国語の略称。当校では、週9時間の英語学習のほかに週2時間の第二外国語学習があてがわれていた。第二外国語はスペイン語、ドイツ語、フランス語、中国語の4つの言語。教師は、英語と兼任の教師であったり、カトリック教会の神父であったり様々。 |
| 生徒の男女比率 | 37期生の総生徒数は約150名。そのうち男子生徒は約15名。完校までこの比率は変わらなかったとか。 |
| 部活動 | 総じて、チアリーディング部とラクロス部が大所帯で人気の部活動だった。中には勝手に陸上部を設立した生徒もいたとかいなかったとか。 |
